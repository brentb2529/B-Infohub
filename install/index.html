Install B-Infohub

Flash the generator bridge straight from this page. No toolchain, no command line.

You need Chrome or Edge on a desktop. Flashing uses Web Serial, which Safari and Firefox do not implement, and which mobile browsers do not expose. This is a browser limitation, not a choice — there is no way around it other than using a supported browser once.
  1. Connect the bridge to your computer with a data USB cable. Charge-only cables are the single most common reason the button below finds nothing — they carry power but no data lines, so the board appears dead to the browser while its power LED is lit.
  2. Click Connect and pick the serial port that appears.
  3. Wait for the flash to finish, then follow the Wi-Fi prompt in the same dialog.

After flashing

The bridge ships with no Wi-Fi network compiled in, deliberately — it is configured once, on the device, and the credentials survive future updates. Three ways in, and the installer above offers the first:

  1. In this page — the install dialog asks for Wi-Fi when flashing finishes.
  2. Bluetooth — the Home Assistant mobile app finds it and offers to set it up.
  3. Its own hotspot — join b-infohub Setup and a captive portal opens.

Then add it to Home Assistant with the EnergyTrak integration. It is discovered automatically on the same subnet; on a routed or VLAN'd network, add it by IP instead.
